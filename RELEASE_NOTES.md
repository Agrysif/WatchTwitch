## 🇷🇺 Исправления

- При запуске Windows сразу в трей плеер получает рабочий размер до первого открытия окна. При включённых категориях приложение самостоятельно восстанавливает сессию или начинает поиск стрима.
- Если видео загрузилось и осталось на паузе, WatchTwitch сначала пробует продолжить просмотр на текущем качестве.

## 🇬🇧 Fixes

- When Windows starts WatchTwitch directly in the tray, the player gets its playback dimensions before the window is first opened. With enabled categories, the app restores the session or searches for a stream automatically.
- If buffered video is paused, WatchTwitch tries to resume it at the current quality before switching quality.
